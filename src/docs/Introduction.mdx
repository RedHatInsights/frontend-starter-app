# Frontend Starter App

This Storybook documents the patterns and components that every HCC frontend application should use.

## What's Included

### Architecture Patterns
- **Feature Islands** — Self-contained feature directories with components, data layer, mocks, and stories
- **ServiceContext DI** — Dependency injection for environment-agnostic data hooks
- **Query Keys Factory** — Structured TanStack Query key management
- **TableView + useTableState** — Unified table state management

### Testing Patterns
- **MSW Handler Factories** — Type-safe, reusable API mocks with spy callbacks
- **ResettableMockCollection** — Mock databases that reset between tests
- **User Journey Stories** — Multi-step play functions testing real user workflows
- **Interaction Helpers** — Reusable helpers for modals, notifications, and form interactions
